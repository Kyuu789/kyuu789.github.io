# 回家五次换乘 · GoHome

河北女孩从苏州回邯郸的返乡小游戏。全程五程：地铁 → 高铁 → 接驳车 → 乡村摆渡车 → 步行进村。

## 第一程 · 苏州地铁

- 三通道躲避跑酷，30 秒内冲进苏州北站。
- 乘客、行李箱障碍，撞到掉一格体力，三次出局。
- 路上随机出现煎饼果子、驴肉火烧、奶茶、泡面、糖葫芦。
- 吃食物加分，但体重上升：人物分三阶段变胖、变道变慢，体重到 100% 直接走不动失败。
- 部分食物带“抢来的”标签，分数 1.8 倍，但更容易吃撑。
- 手机点按变道，电脑支持 ← ↑ → 与 1 2 3。
- 结算星级、体重、吃掉数量、本地最高分；胜利后进入后半程。

## 后半程 · 换乘挑战

- `journey.html` 承接高铁、接驳车、乡村摆渡车、步行四程。
- 每程 3 道情景题，9 秒限时；选错或超时掉一格体力，掉光重走本程。
- 高铁：检票、找车厢、对号入座。
- 接驳车：识别黑车、拒绝绕路加价、确认车站。
- 乡村摆渡车：认村名、绑行李、别下错站。
- 步行进村：拒绝村口黑车、绕坑、遇狗不跑。
- 四程走完进入“妈，我回来了”结局；会读取第一程吃掉的份数和体重，写进结局文案。

## 调试

- 本地在 repo 根目录运行 `python3 -m http.server 8765`，访问 `http://127.0.0.1:8765/GoHome/`。
- 后半程可直接跳程：`journey.html?leg=2` 从高铁开始，`leg=4` 从步行开始。
