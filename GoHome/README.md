# 回家五次换乘 · GoHome

河北女孩从苏州回邯郸的返乡小游戏。第一程为「苏州地铁赶车」，后续四程（高铁、长途接驳车、乡村摆渡车、步行）预留路线节点。

## 已实现

- 三通道躲避跑酷，30 秒内冲进苏州北站。
- 乘客、行李箱障碍，撞到掉一格体力，三次出局。
- 路上随机出现煎饼果子、驴肉火烧、奶茶、泡面、糖葫芦。
- 吃食物加分，但体重上升：人物分三阶段变胖、变道变慢，体重到 100% 直接走不动失败。
- 部分食物带“抢来的”标签，分数 1.8 倍，但更容易吃撑。
- 手机点按变道，电脑支持 ← ↑ → 与 1 2 3。
- 结算星级、体重、吃掉数量、本地最高分。
- WebAudio 合成 BGM 与音效，右上角可静音。
