# 回家五次换乘 · GoHome

河北女孩从苏州回邯郸的返乡小游戏。全程五程：地铁 → 高铁 → 拼车 → 乡村摆渡车 → 步行进村。前四程是操作关，最后一程是夜路躲狗。

## 第一程 · 苏州地铁

- 三通道躲避跑酷，30 秒内冲进苏州北站。
- 背景换成苏州地铁红庄站实景照片，保留通道线和障碍可读性。
- 乘客、行李箱障碍，撞到掉一格体力，三次出局。
- 路上随机出现煎饼果子、驴肉火烧、奶茶、泡面、糖葫芦。
- 吃食物加分，但体重上升：人物分三阶段变胖、变道变慢，体重到 100% 直接走不动失败。
- 部分食物带“抢来的”标签，分数 1.8 倍，但更容易吃撑。
- 手机点按变道，电脑支持 ← ↑ → 与 1 2 3。
- 结算星级、体重、吃掉数量、本地最高分；胜利后进入后半程。

## 后半程 · 四种不同玩法

`journey.html` 承接高铁、接驳车、乡村摆渡车、步行四程。每程 3 格体力，失败只重走本程；场景全部用实景照片做全屏背景，底部是任务卡。

1. **第二程 · 高铁检票**：票面给出检票口（16A / 17A / 18A），在三个闸机里点对，连续 3 次。点错或超时掉体力。
2. **第三程 · 邯郸东拼车**：司机开价 50–80 元，每砍一次降 10 元、掉一格耐心；砍到 30 元点“上车”成交，砍到 20 元司机会翻脸。连续谈成 3 辆。
3. **第四程 · 太行山路摆渡**：车身随机向左或向右倾斜，玩家按反方向压住行李；16 秒内稳住 6 次。压反或超时掉体力。
4. **第五程 · 村口夜路**：狗从左侧或右侧扑来，玩家点另一侧躲开；连续躲 6 次到院门口。慢一步被狗追上就掉体力。

四程走完进入“妈，我回来了”结局；会读取第一程吃掉的份数和体重，写进结局文案。

## 调试

- 本地在 repo 根目录运行 `python3 -m http.server 8765`，访问 `http://127.0.0.1:8765/GoHome/`。
- 后半程可直接跳程：`journey.html?leg=2` 从高铁开始，`leg=3` 接驳车，`leg=4` 山路，`leg=5` 夜路。
- 第一程入口：`index.html`；后半程入口：`journey.html`。
