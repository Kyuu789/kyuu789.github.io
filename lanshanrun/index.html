QUICK GUIDE

画好路线，带上路。

点击地图添加节点。使用撤销、反向或闭合来调整路线；搜索框可定位城市或地址。底图使用高德地图，导出前会自动把国内坐标转回 WGS-84，GPX、TCX、FIT 都能正常识别。距离和圈数可双向换算：输入目标距离会按单圈长度自动换算圈数，输入圈数会自动算出总距离。

轨迹按每秒一个采样点生成，位置、时间、距离严格递增；多圈会自动闭合回起点，不会出现坐标瞬移。GPX 与 TCX 为 XML 轨迹文件；FIT 使用 Garmin 官方 JavaScript SDK 编码，包含活动、轨迹、圈段、会话与消耗估算。所有文件均在浏览器中生成。
