# 词屿 ISLET Android

This Android app is a WebView shell for the live ISLET learning site.

- App ID: `com.islet.words`
- Version: `1.0.0`
- Minimum Android: 6.0 (API 23)
- Site: https://kyuu789.github.io/

The app requires an internet connection. Membership validation remains on the existing Cloudflare Worker. The web app's local data is stored in the app's WebView storage and is separate from Chrome's browser storage.

Build locally with Android Studio or use the repository workflow **Build Android APK**. The workflow uploads a debug APK as a downloadable build artifact.
