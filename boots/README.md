# 靴子抢夺战

靴子抢夺小游戏：草地上 9 个洞，靴子会突然冒出来，点中得分，漏掉断连击。

## 玩法

- 单局 45 秒，靴子出现越来越快，后期会多只同时冒出
- 普通靴 +10 分，金靴 +30 分
- 点空一次立刻结束本局
- 黄色奶龙是障碍，点到会掉马桶冷静 1.5 秒
- 连击每层额外 +2 分（最多 +30）
- 漏掉一只靴子连击归零
- 成绩保存在浏览器 localStorage

## 音频

音效和背景音乐都由 WebAudio 代码实时合成，不依赖外部音频文件，离线也能响。

## 文件

- `index.html` 页面结构
- `style.css` 样式与动画
- `game.js` 游戏逻辑
- `assets/boot.svg` 默认靴子图形
- `assets/naolong.png` 障碍物奶龙

## 换靴子图片

把图片命名为 `boot.png` 放到 `assets/` 目录即可，页面会优先加载它；没有 png 时自动退回 `boot.svg`。建议图片为竖版、背景透明，比例接近 170:210。
